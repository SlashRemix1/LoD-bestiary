# Official Nexon monster-list iframes

These are archived copies of the **iframe documents** loaded by the official
“던전&몬스터” pages, e.g.:

- Shell: `http://lod.nexon.com/game_info/dungeon/dungeon9.asp`
- Iframe: `/game_info/monster/list.asp?category=N` (pagination: `GotoPage=`)

Captured from the Wayback Machine as raw `id_` HTML (EUC-KR/CP949 decoded to UTF-8).

| Category | Area | Notes |
|---|---|---|
| 1 | 우드랜드 | pages 1–2 archived |
| 2 | 지하묘지 | page 1 (page 2 not in Wayback) |
| 4 | 포테의숲 | page 1 (page 2 not in Wayback) |
| 8 | 죽음의마을 | page 1 (pages 2–3 not in Wayback) |

Table columns (confirmed against darkstory HP fit): **Level · HP · EXP · description**.

`s.nx.com` images in these pages were not archived and the host no longer resolves, so those images are hidden. Script and stylesheet links to the old Nexon host were removed so the table still renders.

`dungeons/` holds the 2024–2025 Wayback copies of `dungeon1.asp` through `dungeon9.asp`. Only categories 1, 2, 4, and 8 have a saved monster-list iframe. The other dungeon categories were linked from those shells but never captured.
